CODE FORGE - learn to code in a pixel-art dungeon
==================================================

START PLAYING
  Double-click CodeForge.exe. Nothing to install, no account, no internet needed.

  If Windows says "Windows protected your PC", click "More info", then "Run anyway".
  (The app isn't code-signed yet. Only download it from
  https://github.com/JreyForFun/code-forge/releases)

YOUR PROGRESS
  Saved automatically in %APPDATA%\code_forge\save.txt (a backup is kept as save.bak).
  Changing device or playing on your Android phone too?
    Settings > Export   saves a .codeforge file
    Import progress     (welcome screen or Settings) loads it on the other device

KEYBOARD
  Enter          next / check / continue
  1-5            pick an answer
  Esc            leave a lesson
  Ctrl+Enter/F5  run code in the Spell Lab
