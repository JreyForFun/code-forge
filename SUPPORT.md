# Getting help

**Stuck on a lesson?** Re-read *The Full Scroll* and the summary (you can reopen any cleared
lesson's notes from the course page). On multiple-choice questions, the **HINT** button (costs a few
gems) removes one wrong answer.

**Something isn't working?** Check these first:

| Problem | Try this |
| --- | --- |
| Windows says "Windows protected your PC" | Click **More info**, then **Run anyway**. The app isn't code-signed yet; see [SECURITY.md](SECURITY.md) to verify your download. |
| Android won't install the APK | Allow *Install unknown apps* for the app you opened the file with (Files, Chrome, Drive...). Code Forge needs Android 8.0 or newer. |
| Progress is missing after moving to a new device | Use *Settings → Export* on the old device and *Import progress* on the new one. |
| No sound | Check the Music and Sound sliders in *Settings*, and your device volume. |
| Text is too small | *Settings → Text size*: Normal, Large or Huge. |

**Still stuck?** Search the [issues](https://github.com/JreyForFun/code-forge/issues), then open a
[bug report](https://github.com/JreyForFun/code-forge/issues/new?template=bug_report.yml) if nobody has reported it yet. Include your
device, the version (shown in *Settings*) and what you did just before the problem.
